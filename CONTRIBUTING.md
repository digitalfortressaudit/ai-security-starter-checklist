# Contributing

Pull requests that improve the free checklist, the read-only scan script, or the docs are welcome.

Keep changes small and defensive. This repository is for authorized audits of systems you own or are allowed to assess. Do not add exploit payloads, attack procedures, or material from the paid pack.
